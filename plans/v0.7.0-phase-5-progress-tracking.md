### 7. Fixed Issues
- ✅ **FIXED (2026-01-27):** Text field selection causing modal horizontal scroll.
  - **Problem:** Dragging to select text in input fields caused the modal to shift horizontally, even with short text that fit within the field.
  - **Root Cause:** Browser's native text selection mechanism sets `scrollLeft` values on modal containers during drag operations. CSS overflow/overscroll properties cannot prevent this internal scroll value from being set.
  - **Solution:** JavaScript-based fix using `requestAnimationFrame` to monitor and reset `scrollLeft` to 0 on modal containers 60 times per second. This prevents any horizontal scroll from ever being visible.
  - **Implementation:** `preventModalHorizontalScroll()` function in `dist/main.js` (lines 4102-4135)
  - **CSS Cleanup:** Removed redundant/ineffective CSS overflow properties, kept useful `overscroll-behavior-x: contain` for trackpad scroll-chaining prevention.
