# v0.7.0 Phase 4C: Individual Export/Import UI

## Overview
Add individual export capabilities via profile card action menus and group context menus, with auto-detecting import that handles single profiles, groups, or full exports. No dedicated export modal - all exports are direct actions.

---

## User Vision

### Profile Cards
- **Connect** button (unchanged)
- **Edit** button (unchanged)
- **Actions** button (labeled "Actions") with context menu:
  - **Duplicate** - same behavior as current duplicate button
  - **Export** - NEW: exports this profile only
  - **Delete** - same behavior as current delete button

### Group Context Menu
- Rename (existing)
- Add Subgroup (existing)
- **Export** - NEW: exports this group with all sub-groups and profiles
- Delete (existing)

### Settings
- **Export All Profiles** button (renamed from "Export Profiles")
  - Exports everything (same behavior as current export)
- **Import Profiles** button (unchanged name)
  - Auto-detects file type: single profile, group, or all profiles
  - Routes to appropriate handler automatically

### Conflict Resolution
- Use **buttons** for duplicate strategies, not dropdowns or radio buttons
- Profile conflicts: **Skip** | **Rename** | **Overwrite**
- Group conflicts: **Skip** | **Rename** | **Merge**

---

## Backend Commands (Already Complete - Phase 4B)

```rust
export_profile(profile_id, include_password) → JSON string

export_profiles(include_passwords) → JSON string // existing

import_group(data, parent_group_id, duplicate_action) → new group ID
import_profiles(data) → () // existing
```

**Duplicate Actions:**
- Profile: "skip", "rename", "overwrite"
- Group: "skip", "rename", "merge"

### Part 5: Auto-Detecting Import

**5.1 Refactor importProfiles() to Router**
- File: `dist/main.js` line ~4998
- New logic:
```javascript
async function importProfiles(file) {
    showToast('Importing...', TOAST_DURATION_LOADING);

    try {
        const text = await file.text();
        const data = JSON.parse(text);

        // Auto-detect import type
        const importType = detectImportType(data);

        if (!importType) {
            throw new Error('Invalid import file format');
        }

        // Route to appropriate handler
        if (importType === 'profile') {
            await importSingleProfile(data);
        } else if (importType === 'group') {
            await importSingleGroup(data);
        } else if (importType === 'all') {
            await importAllProfiles(data);
        }

    } catch (error) {
        console.error('Import failed:', error);
        showToast(cleanErrorMessage(error), TOAST_DURATION_LONG, 'error');
    }
}
```

## Error Handling

### Export Errors
- Profile not found → "Profile no longer exists"
- Group not found → "Group no longer exists"
- File save cancelled by user → silent, no toast
- File save failed → "Failed to save file: {error}"

### Import Errors
- Invalid JSON → "Import file is corrupted or invalid"
- Missing exportFormatVersion → auto-default to "1.0", migrate
- Future version → "This file requires a newer version of SSH Profile Manager"
- Max depth exceeded → "Cannot import: would exceed maximum group depth (3 levels)"
- Backend error → show cleaned error message

## Alternatives Considered

### Alternative 1: Separate Export/Duplicate/Delete Buttons
- **Rejected:** Too cluttered, 4-5 buttons per card
- **Chosen:** Single Actions menu consolidates less-frequent actions

### Alternative 2: Export Modal for Mode Selection
- **Rejected:** User wants direct actions, no modal friction
- **Chosen:** Context menus and Settings button for direct export

### Alternative 3: Radio Buttons for Conflict Resolution
- **Rejected:** User specifically wants buttons
- **Chosen:** Horizontal button layout with clear labels

### Alternative 4: Dropdown for Duplicate Strategy
- **Rejected:** Requires two actions (select + confirm)
- **Chosen:** Direct button clicks (one action)
