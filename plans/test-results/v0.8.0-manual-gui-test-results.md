### Summary
- **Total Tests (macOS):** All sections 1–8 complete (Section 9 N/A — TCC permission test skipped)
- **Passed:** All (macOS)
- **Failed:** 0
- **Blocked:** 0 (Section 9 deferred — requires manual TCC permission revocation)

### Issues Fixed During Testing
1. **Drag to Ungrouped (empty)** — Ungrouped section not visible when no ungrouped profiles exist. Fixed: empty Ungrouped drop zone now rendered in DOM and revealed during drag.
2. **Reset Sorting Order button** — Both Settings button and confirmation modal "Reset" button changed from `btn-secondary` to `btn-danger` (red).
3. **Text highlighting during drag** — Text in profile titles, group names, and info values was selectable while dragging. Fixed: `user-select: none` applied to these elements during `drag-in-progress`.
4. **Settings Tab cycle** — Tab reached last Settings item and escaped to main window instead of cycling. Fixed: `tabindex="-1"` on `settings-content` scroll container + `focusin` safety-net listener.
5. **Settings section dividers** — No visual separator between Settings sections. Fixed: `border-top` divider applied to all section boundaries via CSS sibling selector.

### Performance Notes
No performance issues observed. Drag and drop, profile loading, and all modal interactions feel responsive.

### Additional Observations
- Section 9 (macOS Terminal Connection Error Feedback) not tested — requires manually revoking TCC Accessibility permission which is difficult to trigger reliably.
- Windows testing pending.
