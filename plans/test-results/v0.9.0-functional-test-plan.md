# Functional GUI Test Plan — v0.9.0

**Purpose:** Focused functional testing of all new features introduced in v0.9.0. Existing features not touched by this release are not retested here.
**Scope:** SSH_ASKPASS password auth (Phase 1), Central Passwords Manager UI (Phase 4), Profile Modal — Central Password auth method (Phase 5), Export/Import for Central Passwords (Phase 3), and edge cases.
**Platform:** macOS (Apple Silicon) only.

> Note: This is NOT the full regression test. Full GUI regression is covered by the standard manual GUI test plan template. This plan is executed as Phase 7 of the v0.9.0 development process, before entering the pre-release checklist.

---

## Pre-Testing Setup

### Requirements
- App built from `v0.9.0-dev` branch (`bun run build` — do not use `bun run dev` for connection testing as SSH_ASKPASS requires a production build)
- Access to a live SSH server or a loopback SSH target (steps marked **[requires SSH server]** cannot be verified without one)
- macOS Keychain accessible (no restrictions on `ssh-profile-manager` service)
- Developer Tools open (View → Developer Tools) to monitor console for errors

### Test Data Creation

Create the following before beginning tests. Use exact names as shown — many test steps reference them by name.

**Groups:**
- [ ] Create group `Test-Group-A` (top-level)
- [ ] Create group `Test-Group-B` (top-level)

**Central Passwords (created during testing — do not pre-create):**
- These are created as part of the test steps below
