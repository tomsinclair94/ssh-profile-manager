## Migration Scope

### Bundle Identifier Change

**⚠️ BREAKING CHANGE:** v0.7.0 changes the bundle identifier for better branding.

**Old identifier:** `com.tomsinclair.sshprofilemanager` (v0.6.5 and earlier)
**New identifier:** `com.sshprofilemanager.app` (v0.7.0+)

**What Gets Migrated Automatically:**
- ✅ **Database file** - Copied from old location to new location
- ✅ **Keychain passwords** - Copied from old service name to new service name
- ✅ **User settings** - Preserved in database (terminal preference, etc.)
- ❌ **localStorage data** - Will reset to defaults (theme, window size, collapsed groups)

**User Impact:** Seamless - users won't notice. On first v0.7.0 launch, migration runs automatically and all profiles/settings are preserved. Only localStorage preferences reset (which is acceptable as v0.7.0 has new defaults).

**Implementation Status:** ✅ Complete (2026-02-17)
- Backend implementation: ✅ Complete
- Automated tests: ✅ Complete (5 new tests, all passing)
- Manual testing: 🔄 In Progress
- Documentation: ⏸️ Pending (Phase 8F)

### Database Changes (Schema v3 → v4)

**New Tables:**
- `groups` - Hierarchical group structure with parent_id and path
- `profile_metadata` - Icons, favourites, display order for profiles
- `tags` - Tag definitions with names and colors
- `profile_tags` - Many-to-many relationship between profiles and tags

**Schema Migrations:**
- Extract groups from `profiles.group_name` field → create entries in `groups` table
- Update all profiles to reference group IDs via `group_path`
- Backfill `profile_metadata` for all existing profiles with defaults:
  - `icon` = 'server'
  - `is_favorite` = 0
  - `display_order` = 0

### Frontend Migrations

**localStorage Changes:**
- ⚠️ **All localStorage will be reset** due to bundle identifier change (WebView storage is tied to bundle ID)
- Fresh defaults applied: dark theme, expanded groups, default window size
- Users will need to reconfigure preferences (acceptable trade-off for clean v0.7.0 start)

### New Features to Validate

- **Hierarchical Groups:** Up to 3 levels deep, semantic paths (e.g., "Work/Production/Servers")
- **Favourites System:** Virtual "Favourites" group, star toggle on profiles
- **Profile Icons:** 40+ Lucide icons, searchable picker, default 'server'
- **Tags:** Color-coded badges, multi-select assignment, search filtering
